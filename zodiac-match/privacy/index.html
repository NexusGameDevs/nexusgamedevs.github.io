Privacy policy

Zodiac Match by Nexus Game Development. Effective October 27, 2026.

Zodiac Match is a game for children. We built it so that it does not need to know anything about the person playing it. This page explains what the game does and does not do with information.

What we collect

Nothing. The game does not ask for a name, email address, age, location, photos, contacts or any other personal information. There is no account and no sign in.

What stays on the device

The game saves progress, stars, stickers and settings in a file on the phone or tablet so that play can continue next time. This file is never sent to us or to anyone else. Uninstalling the game deletes it, and "Start over" in the settings clears it.

Spoken animal names

When "Say names" is on, the game uses the text to speech voice already built into the device. The game sends only the animal's name to that voice. It does not record or listen to anything.

Internet, ads and analytics

The game plays fully offline. It contains no analytics, no tracking, no advertising identifiers and no social features. Players cannot chat with or contact anyone.

Purchases

Extra level sets can be bought inside the game. Buying always sits behind a grown-up check. Payment is handled entirely by Google Play under Google's own privacy policy. We never see card details or the buyer's identity.

Children

Because we collect no personal information, we do not collect personal information from children under 13 or any other age. This meets the Children's Online Privacy Protection Act (COPPA) and the Google Play Families policy.

Changes

If a future version of the game changes any of this, for example by showing ads, we will update this page first and change the date at the top.
